## Configuration

Everything that belongs to one specific environment lives in configuration, never in the code: hostnames, addresses, credentials. Examples in this repository use the documentation ranges from RFC 5737 (192.0.2.0/24, 198.51.100.0/24 and 203.0.113.0/24) and example.com, so they never point at a real network.
